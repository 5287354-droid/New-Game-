# 音まわりの土台(sound-lab)

音はすべて Web Audio の合成。外部の音源ファイルは使わない(出どころは `assets/audio/_provenance.csv`)。

## 音の経路

```
BGM(曲ごとの補正) → bgmIn(BGM音量) → tone(籠らせるローパス) → duck(ジングル中に下げる) ┐
SE ────────────────→ se(SE音量) ───────────────────────────────────────────────────┤
環境音 ────────────→ amb(SE音量x.55) ──────────────────────────────────────────────┤→ master → コンプレッサー(-14dB, 4:1) → リミッター(-4dB, 20:1) → 出力
ジングル ──────────→ jin(SE音量) ──────────────────────────────────────────────────┘
```

## 音量設定
- `state.bgmVol` / `state.seVol`: 0・.25・.5・.75・1 の5段階(既定 .75)。`fresh()` と `migrate()` で補う(`state.v` は 1 のまま)。むかしの `bgmVol` の値は5段階に丸める。
- UI は `volCtl()`(タイトル画面と、画面下のフッター)。駅サイン調の数字チップ(0/25/50/75/100)。
- 実効ゲインは `volGain(v)=v^1.6`(耳の感覚に合わせた曲線)。
- ♪(BGM) と SE のオン・オフは、これまでどおり別に残す。

## 他の班が呼べる関数

| 関数 | 引数 | 用途 |
|---|---|---|
| `sfx(name, rate=1)` | name は下の一覧。rate は音程の倍率 | 効果音。カウントアップは rate を少しずつ上げて呼ぶ |
| `jingle(name)` | `win` `rare` `shiny` `awaken` `station` | ジングル(BGMを下げて、終わったら戻す) |
| `jingleLen(name)` | name | ジングルの長さ(秒)。演出のタイミング合わせ用 |
| `ambStart(name)` / `ambStop()` | `'rain'` `'wind'` | 環境音のループ。`'rain'` は BGM も自動で籠らせる(`bgmSetMood({rain:true})`)。SE オフ・音量0のときは鳴らない |
| `bgmSetLayer(role, on)` | role: `lead` `har` `arp` `bass` `drum` `drumx`。on: true/false、null で手動をやめる | パートを入り切り |
| `bgmSetMood(obj)` | `{night, danger, lowHp, rain, fog}`(真偽値) | 状況を知らせる。天気(T1)はここを呼ぶだけ |
| `audioVolumes()` | なし | 音量設定を変えたあとに呼ぶ(設定UIは呼んでいる) |

### SE 一覧(`SFX`)
`ui_ok` `ui_back` `sel` `hit` `crit` `ko` `heal` `lvup`(= `levelup`) `countup` `newdex` `rare`(レア出現の前兆) `shiny` `kirari` `stamp` `rain` `wind` `station` `scout` `breed` `win` `lose`。UI系(ui_ok/ui_back/sel)は三角波の短い音で統一。`hit` `crit` はノコギリ波主体をやめ、ノイズの打撃音と低い三角波にして耳に刺さらなくした。

### 適応型BGM
- 夜(`state.time===3`)は、ハモリと分散和音を抜く。
- ぬし戦・ライバル戦(`danger`)、味方のHPが3割以下(`lowHp`)は、ドラムを足す(`drumx`: 1・3拍目のキック。もともとテンポの速い曲(BPM130以上と戦闘調)には足さない)。
- 雨は 1900Hz、霧は 1000Hz のローパスで籠らせる(0.5秒かけて変化)。
- 夜・danger・lowHp は `bgmUpdate()` が画面の状態から自動で決める。`bgmSetMood` の値が優先される。
- 天気(T1)はまだ無いので、`bgmSetMood({rain:true})` `bgmSetMood({fog:true})` と `ambStart('rain')` を呼ぶのが入口。

## ループの継ぎ目
- 調整前は、ドラムが最初から全開の音量で始まり、クリックの元になっていた(1165 個の音量エンベロープが 0 でなく始まっていた)。2〜3msの立ち上がりをつけ、調整後は **0 / 4923**(すべて 0.0001 から始まり 0.0001 で終わる)。
- パートごとのループ長は、短いパートがいちばん長いパートの約数になっていれば、何周かで揃って継ぎ目がずれない。割り切れない曲が5つあった(hinoshima 30,16,4 / kagutsuchi 34,16,4 / sango 31,16,4 / nirai 34,16,4 / orochi 28,8,4)ので直した。メロディは変えず、休符で足してそろえた: hinoshima・sango・orochi は主旋律の最後に休符を足して32拍、kagutsuchi・nirai は主旋律を36拍にして、ベースを同じコード進行の繰り返し+2小節ぶんで36拍に。これで全31曲が割り切れる(`tools/audio_levels.js` の判定は「なし」)。

## まぼろし駅(T8)の曲 mabo と踏切SE
- `mabo`: 62BPM の仮曲を作り直した。BPM58、64拍(約66秒)。オルゴールの自作旋律(Aドリア風、Am-F-Dm-E と C-G-F-E の2つのまとまり)に、1オクターブ上のきらめき、低いベース、古い発車ベルの音(e6 と b5 を、まばらに1回ずつと、最後に4連の細かい連打)を重ねる。
- 夜専用の曲なので、夜に抜かれる「ハモリ」「分散和音」に頼らない。ベルとオルゴールは `role:'lead'` で常に鳴る(`bgmChannels` が曲定義の `role` を使えるようにした)。霧のローパス(1000Hz)がかかっても、旋律は o5〜o6 中心なので聞き取れる。
- `fumikiri`(幽霊列車の踏切ベル): mabo の発車ベルと同じ e6・b5。音量を .05 → .04 に下げ、余韻を少し伸ばして倍音をうっすら足した。耳に刺さらない。
- 測り直し(31曲): RMS 平均 -24.00 標準偏差 0.02(最小 -24.04 / 最大 -23.97、幅 0.07 dB)。mabo は補正 1.73 で -24.00。ピーク最大 -1.96 dBFS(0 に届かない)。エンベロープ不良 0 / 4964。

## 注意点
- ブラウザは最初のタップまで音を出せない。`pointerdown` で `resume()` する既存の仕組みを残した。
- ジングルは SE オン(`state.sound`)のときだけ鳴る。BGM だけオンでも、ジングルは鳴らない。


## 効果音がBGMに埋もれる問題の調整(監査 指摘3)

測り方: `node tools/audio_levels.js --sfx`。SE・ジングルも BGM と同じ経路(se/jin → master → コンプレッサー → リミッター)で、音量75%。BGM の短時間ラウドネスは 400ms 窓 RMS の中央値(約 -24 dBFS)、SE は短いので 100ms 窓 RMS の最大値。「BGM差」は BGM との差(LU 相当)。
調整: 音ごとの補正 `SFX_TRIM`、見せ場の音が鳴る間だけ BGM を下げるダッキング `SFX_DUCK`、細い音(sel・ui_ok・ui_back・countup・kirari・shiny)に低い成分を追加。全SEのピークは -7 dBFS 以下(目標 -1 以下)。環境音の rain は元から細かいクリックでピークが高かったので、小さめにして -7.8 に収めた。
試聴: `docs/update/audio_preview/sfx_over_bgm_before.mp3` と `_after.mp3`(komorebi と battle の上に SE を順に鳴らす。`node tools/audio_preview.js docs/update/audio_preview --sfxmix=名前 [--html=…]`)。
