# RECON（偵察まとめ）

詳細: [recon_systems.md](recon_systems.md)（システム・セーブ）／[recon_assets.md](recon_assets.md)（絵・音・演出）／[recon_play.md](recon_play.md)（実プレイ所見）／スクショ [before/](before/)

## 技術
- 素のJavaScriptの単一HTML（`src/game.html` 6911行）。DOMの文字列テンプレート＋Canvas 2D。依存パッケージなし、テストなし。
- 歩けるマップのエンジンは `src/parts/overworld.js`。game.html の同じ部分とずれが1か所ある（`wildCard`。game.html のほうが新しい）。
- アプリ版は `python3 tools/build_app.py src/game.html .` で index.html・sw.js を作る。main ブランチの index.html が公開版（推測）。
- 撮影は `node tools/shots.js <出力先>`（スマホ幅390×844、40画面）。

## システム（実際にあるもの）
- 9町・44マップ・時間帯4つ（120歩ごとに進む）。天候はない。
- 魔生物159体（図鑑141＋ガチャ18）、系統10、技68、特性27、性格8。進化は四神の覚醒だけ。色違いは野生1/150、配合1/40。
- 戦闘（3対多のコマンド式・オート・スカウト）、配合（特殊配合15・血統・突然変異・隔世遺伝・触媒）、+強化、育て屋。
- 経済: 円・流星石（ガチャ）、コンビニ・研究所の売店・交換所・行商人。依頼15件、配合杯、ぬし／裏ぬし／荒ぶるぬし、星界の塔、デイリー、ログインボーナス。
- マップの仕掛けは非常に豊富（信号、潮、釣り、溶岩、トロッコ、吹雪、流氷、突風、鏡、霧など）。

## セーブ
- localStorage `michikusa-save-v1`、`state.v=1`。`load()` は v≠1 を拒否する。`migrate()` は足りないキーを補う追記型。クラウド保存は任意。
- → 新しいキーは「足りなければ補う」形で追加する。v を上げるなら、load の判定と移行処理を同時に変える。

## アセット
- 絵: 全159体が手続き描画（`flatPainter` / `sprite()`）。埋め込み画像は0。**目を描く `eye()` を使う定義は155件中56件だけ**。色違いは CSS の hue-rotate のみ。
- 音: Web Audio 合成のみ。BGM 30曲（MML風）、SE 10種。音量は ON/OFF だけ。ライセンス上の懸念はない（すべて自作コード）。
- 演出: CSSキーフレーム、揺れ、フラッシュ、ガチャ演出、カットイン。

## 実プレイで見えた弱点
- マップが画面の半分。上下に黒い余白が大きい。
- 戦闘ボタンが11個並び、どれが主か分からない。敵HPの数値が見えない。勝利画面の報酬感が薄い。
- 初戦で負けうる（負けると所持金が半分になる）。会話のスキップがない。タブ名が切れる。
- 町の「探索する」は88%が必ず戦闘で、寄り道の判断がない。
- 色違い・レア出現に特別な演出がほぼない。見つけた瞬間の気持ちよさが弱い。
