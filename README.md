# ミチクサ鉄道

ローカル線を降りて、草むらで魔生物と出会う。歩いて、スカウトして、配合して育てるRPG。

「ジェンガルア配合録」の魔生物・戦闘・配合をもとに、見下ろしマップを歩いて冒険する形に作り直しているゲームです。

## 遊び方

- マップをタップすると、その場所まで自動で歩く。人・看板・扉・海をタップすると、そばまで歩いて話す・調べる・入る・釣りまでする
- マップを押し続けると、主人公から見て指の方向へ歩く
- 十字キーでも歩ける。Aで話す・調べる、Bを押しながら走る(キーボード: 矢印 / Z / X)
- 自動で歩いていても仕掛けはそのまま効く(車・突風・蜘蛛の巣・満ち潮・出会いで止まる)。霧や暗闇では見えている範囲しかタップで行けず、鏡の中ではタップ移動が効かない
- 草むらを歩くと魔生物が出てくる。朝・昼・夕方・夜で、出てくる魔生物も町の景色も変わる
- 家で休むと回復、研究所で配合、コンビニで買い物、駅から電車でほかの町へ

いま歩けるのは、こもれび町(鎮守の森・裏山)、霞ヶ丘(路地裏・地下鉄のトンネル・廃ビル)、潮見浜(砂浜と磯・夜の漁港・灯台下の海蝕洞)、天狗岳(杉林の参道・渓流の吊り橋・奥宮への石段)、マヨイガ(屋敷・霧の竹林・鏡の湖・千本鳥居)、流氷岬(雪の原生林・流氷の海・オーロラの丘)。ほかの駅は、駅の中からこれまでどおりメニューで遊べます。

### 霞ヶ丘のしかけ
- 信号と車: 歩行者の信号が青のあいだだけ、車が横断歩道の手前で止まる。赤で渡るとはね返される
- 路地裏の迷路とゴミ箱: ゴミ箱は1日1回ずつ調べられる(道具・お金・魔生物が飛び出すことも)
- まっ暗な地下鉄のトンネル: レバーでシャッターを開け、配電盤で明かりをつける。配電盤は路地裏の廃ビルのシャッターにもつながっている
- 廃ビルの蜘蛛の巣: ふむと少しのあいだ動けない。最上階に女郎蜘蛛

### 潮見浜のしかけ
- 潮の満ち引き: 朝と夕方は満潮、昼と夜は干潮。干潮のときだけ干潟を歩いて沖の小島へ渡れる。満ちてくると岸へ押しもどされる
- ベンチ: 海をながめると時間が進む。潮だまりは干潮のときだけ、1日1回ずつのぞける
- 釣り: 漁港の網元ケンジから釣りざおをもらうと、海に向かってAで釣りができる。「！」が出た瞬間にAで釣り上げる
- 大潮の夜の大蟹: 夜にだけ桟橋の先に上がってくる
- 灯台: 夜になると光がぐるりと回る
- 灯台下の海蝕洞(大蟹を倒すと入れる): 岩を押して穴を埋めるパズル。マップを出入りすると岩は元の位置にもどる

### 天狗岳のしかけ
- 杉林の参道: 深い霧で数マス先しか見えない。分かれ道ではお地蔵さまの見つめる方が正解。ちがう道はもとの場所にもどされる
- 渓流の吊り橋: 7秒ごとに突風。木の葉が舞いはじめたら合図で、風のあいだは橋を渡れず、橋の上にいると押しもどされる。飛び石で中州へ
- 奥宮への石段: 石碑の謎かけ(東→西→南→北)の順に灯籠へ狐火を灯すと、ぬしの前の結界がとける。順番をまちがえると火が消える

### マヨイガのしかけ
- 迷い家の屋敷: ふすまを開けるたびに奥の間が入れかわる(座敷わらしで回復・お膳で道具・魔生物の待ちぶせ・掛け軸のヒント・空き部屋)
- 霧の竹林: キノコの輪(狐の通り道)をふむと、対になる輪へとぶ。夜だけ光る竹から才能のかけら
- 鏡の湖: 鏡にふれると左右反転した「湖の鏡」へ。中では十字キーの左右が逆になり、飛び石で湖の島へ渡れる
- 千本鳥居: 鳥居をくぐるあいだに上(後ろ)を向くと入口へもどされる。奥にぬしの鵺、たおすと雲海の崖に裏のぬしソラクジラ

### 流氷岬のしかけ
- 寒さ: 雪の原生林・流氷の海・オーロラの丘では、歩くたびに左下の寒さゲージがたまる(ふかい雪と地吹雪の中は倍)。焚き火をAで調べるとあたたまり、そこが目ざめる場所になる。ゲージがいっぱいになると、なかまのHPが減って最後の焚き火の前へもどされる
- すべる氷: 町の池と沖の氷原は、何かにぶつかるか氷の外に出るまで止まれない。池の穴の前で止まると穴釣りができる
- ふかい雪: 歩くのが遅くなり、魔生物も出る
- 地吹雪(雪の原生林): ときどき、まっ白で数マス先しか見えなくなる
- 雪玉とクレバス(雪の原生林): 雪玉を押してクレバスに落とすと橋になる。東のふかい雪を大回りする道もあるが、とても寒い。マップを出入りすると雪玉は元にもどる。南西に秘湯(回復)
- 流氷(流氷の海): 朝昼と夕夜で、流れつく流氷が変わる。沖の氷原へは朝昼、氷原から王者の海へは夕夜。乗っている流氷が流されると岸へもどされる。ベンチで時間を進められる
- 薄氷: 同じ所を2度ふむと割れて落ちる(HPが減って、手前にもどされる)。氷から出ると割れ目はまた凍る。オーロラの丘の湖は、全部の氷を一度ずつふむと宝が出る
- オーロラの橋(オーロラの丘): 夕方と夜だけ、クレバスに光の橋がかかる。裏のぬしアマノツルも夕夜だけ現れる
- 流氷の王者を倒すと、原生林の奥(オーロラの丘)の吹雪がおさまり、帰りは観光船で岬へもどれる

### レベル
歩くと出会う回数が多いので、野生は元の1.25倍、ぬしとライバルは1.2倍、裏のぬしは1.15倍にしている(`OW_LV`)。

## 作り方

- ゲーム本体: `src/game.html`
- 歩けるマップ: `src/parts/overworld.js` の内容が `src/game.html` に入っている
- アプリ版を作る: `python3 tools/build_app.py src/game.html .`(`index.html`・`sw.js`・`manifest.webmanifest` ができる)
- アイコン: `python3 tools/make_icons.py icons`
- イラストの埋めこみ: `python3 tools/embed_art.py`

セーブは「ジェンガルア配合録」とは別の場所(`michikusa-save-v1`)に保存されます。
