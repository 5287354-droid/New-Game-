# ミチクサ鉄道

ローカル線を降りて、草むらで魔生物と出会う。歩いて、スカウトして、配合して育てるRPG。

「ジェンガルア配合録」の魔生物・戦闘・配合をもとに、見下ろしマップを歩いて冒険する形に作り直しているゲームです。

## 遊び方

- 十字キーで歩く、Aで話す・調べる、Bを押しながら走る(キーボード: 矢印 / Z / X)
- 草むらを歩くと魔生物が出てくる。朝・昼・夕方・夜で、出てくる魔生物も町の景色も変わる
- 家で休むと回復、研究所で配合、コンビニで買い物、駅から電車でほかの町へ

いま歩けるのは、こもれび町(鎮守の森・裏山)と霞ヶ丘(路地裏・地下鉄のトンネル・廃ビル)。ほかの駅は、駅の中からこれまでどおりメニューで遊べます。

### 霞ヶ丘のしかけ
- 信号と車: 歩行者の信号が青のあいだだけ、車が横断歩道の手前で止まる。赤で渡るとはね返される
- 路地裏の迷路とゴミ箱: ゴミ箱は1日1回ずつ調べられる(道具・お金・魔生物が飛び出すことも)
- まっ暗な地下鉄のトンネル: レバーでシャッターを開け、配電盤で明かりをつける。配電盤は路地裏の廃ビルのシャッターにもつながっている
- 廃ビルの蜘蛛の巣: ふむと少しのあいだ動けない。最上階に女郎蜘蛛

## 作り方

- ゲーム本体: `src/game.html`
- 歩けるマップ: `src/parts/overworld.js` の内容が `src/game.html` に入っている
- アプリ版を作る: `python3 tools/build_app.py src/game.html .`(`index.html`・`sw.js`・`manifest.webmanifest` ができる)
- アイコン: `python3 tools/make_icons.py icons`
- イラストの埋めこみ: `python3 tools/embed_art.py`

セーブは「ジェンガルア配合録」とは別の場所(`michikusa-save-v1`)に保存されます。
