# ミチクサ鉄道

ローカル線を降りて、草むらで魔生物と出会う。歩いて、スカウトして、配合して育てるRPG。

「ジェンガルア配合録」の魔生物・戦闘・配合をもとに、見下ろしマップを歩いて冒険する形に作り直しているゲームです。

## 遊び方

- マップをタップすると、その場所まで自動で歩く。人・看板・扉・海をタップすると、そばまで歩いて話す・調べる・入る・釣りまでする
- マップを押し続けると、主人公から見て指の方向へ歩く
- 十字キーでも歩ける。Aで話す・調べる、Bを押しながら走る(キーボード: 矢印 / Z / X)
- 自動で歩いていても仕掛けはそのまま効く(車・突風・蜘蛛の巣・満ち潮・出会いで止まる)。霧や暗闇では見えている範囲しかタップで行けず、鏡の中ではタップ移動が効かない
- 草むらを歩くと魔生物が出てくる。朝・昼・夕方・夜で、出てくる魔生物も町の景色も変わる
- 町の外のマップでは、Bボタンの左の「駅へもどる」を2回押すと、いつでも町の駅の前へもどれる(追われているあいだは使えない)
- 岩や雪玉でうめた穴は、ずっとうまったまま。氷山の洞窟の氷塊も、動かした場所をおぼえている(入口の氷の壁の文字を2回調べると、はじめの場所にもどせる)
- 家で休むと回復、研究所で配合、コンビニで買い物、駅から電車でほかの町へ

いま歩けるのは、こもれび町(鎮守の森・裏山)、霞ヶ丘(路地裏・地下鉄のトンネル・廃ビル)、潮見浜(砂浜と磯・夜の漁港・灯台下の海蝕洞)、天狗岳(杉林の参道・渓流の吊り橋・奥宮への石段)、マヨイガ(屋敷・霧の竹林・鏡の湖・千本鳥居)、流氷岬(雪の原生林・流氷の海・オーロラの丘)、火ノ島(溶岩の黒い浜・地獄谷・溶岩洞・火口のふち)、珊瑚島(白い砂浜・マングローブの森・珊瑚礁の海)、終点の黄泉ヶ原(彼岸花の原・忘れ川のほとり・川の向こう・ひらさかの上)。ほかの駅は、駅の中からこれまでどおりメニューで遊べます。

### 霞ヶ丘のしかけ
- 信号と車: 歩行者の信号が青のあいだだけ、車が横断歩道の手前で止まる。赤で渡るとはね返される
- 路地裏の迷路とゴミ箱: ゴミ箱は1日1回ずつ調べられる(道具・お金・魔生物が飛び出すことも)
- まっ暗な地下鉄のトンネル: レバーでシャッターを開け、配電盤で明かりをつける。配電盤は路地裏の廃ビルのシャッターにもつながっている
- 廃ビルの蜘蛛の巣: ふむと少しのあいだ動けない。最上階に女郎蜘蛛

### 潮見浜のしかけ
- 潮の満ち引き: 朝と夕方は満潮、昼と夜は干潮。干潮のときだけ干潟を歩いて沖の小島へ渡れる。満ちてくると岸へ押しもどされる
- ベンチ: 海をながめると時間が進む。潮だまりは干潮のときだけ、1日1回ずつのぞける
- 釣り: 漁港の網元ケンジから釣りざおをもらうと、海に向かってAで釣りができる。「！」が出た瞬間にAで釣り上げる
- 大潮の夜の大蟹: 夜にだけ桟橋の先に上がってくる
- 灯台: 夜になると光がぐるりと回る
- 灯台下の海蝕洞(大蟹を倒すと入れる): 岩を押して穴を埋めるパズル。マップを出入りすると岩は元の位置にもどる

### 天狗岳のしかけ
- 杉林の参道: 深い霧で数マス先しか見えない。分かれ道ではお地蔵さまの見つめる方が正解。ちがう道はもとの場所にもどされる
- 渓流の吊り橋: 7秒ごとに突風。木の葉が舞いはじめたら合図で、風のあいだは橋を渡れず、橋の上にいると押しもどされる。飛び石で中州へ
- 奥宮への石段: 石碑の謎かけ(東→西→南→北)の順に灯籠へ狐火を灯すと、ぬしの前の結界がとける。順番をまちがえると火が消える

### マヨイガのしかけ
- 迷い家の屋敷: ふすまを開けるたびに奥の間が入れかわる(座敷わらしで回復・お膳で道具・魔生物の待ちぶせ・掛け軸のヒント・空き部屋)
- 霧の竹林: キノコの輪(狐の通り道)をふむと、対になる輪へとぶ。夜だけ光る竹から才能のかけら
- 鏡の湖: 鏡にふれると左右反転した「湖の鏡」へ。中では十字キーの左右が逆になり、飛び石で湖の島へ渡れる
- 千本鳥居: 鳥居をくぐるあいだに上(後ろ)を向くと入口へもどされる。奥にぬしの鵺、たおすと雲海の崖に裏のぬしソラクジラ

### 奥地(それぞれの町のぬしを鎮めると入れる)
町が進むほど広く、むずかしくなる。いちばん奥に大きな宝箱がある。出てくる魔生物は、その町の探索先より少し強い。
- こもれび町「大楠の迷い森」(44×40・鎮守の森の西から): 丸太の渡しで川をこえる。朝昼は蓮の葉、夕夜は蛍の石が川の道になる。キノコの輪を正しくたどると大楠へ。岩を押して小川の穴をうめる
- 霞ヶ丘「旧環状線」(52×40・地下鉄トンネルの東から): トロッコで環状線を回る。分かれ道は4か所、切りかえレバーは北の駅と東の車庫。2本のレバーを正しい順で切りかえると南の駅へ着く
- 潮見浜「沖の岩礁と難破船」(56×44・砂浜の西から): 干潮のあいだだけ干潟を渡り、流れるいかだで難破船へ。甲板の床板はくさっていて、ふむと1秒でぬける。甲板の下から大ダコの足が突き上げてくる
- 天狗岳「天狗の修験道」(56×56・奥宮の東から): 落石の沢、両がわが谷の風の尾根(天狗風で押し流される。岩の東がわにかくれる)、崩れ橋、天狗風に乗って飛ぶ飛び石。山頂に天狗
- マヨイガ「裏座敷・鬼火の回廊」(48×48・里の東のふすまから): みがかれた廊下はすべる。まんなかの鬼火を手燭にうつし、46歩のうちに四すみの燭台へ運ぶ(キノコの輪が近道)。四つともともすと奥の間がひらく

### 流氷岬のしかけ(第2版)
マップは火ノ島と同じくらいの広さ(雪の原生林 64×54、流氷の海 64×70、氷山の洞窟 48×46、オーロラの丘 56×52)。
- 寒さ: 雪のマップでは歩くたびに寒さゲージがたまる(ふかい雪は倍)。焚き火をAで調べるとあたたまり、たおれたときはそこで目をさます
- 地吹雪と押し流し: 地吹雪のあいだ、ふかい雪の上にいると西へ押し流される。木や岩の東がわにいると平気。押し流された先がクレバスなら落ちる(焚き火の前へもどされる)
- 雪崩: 斜面の通り道に、上から雪崩がくる。雪けむりが立ったら合図。のまれると斜面の下まで流される
- 雪玉とクレバス(雪の原生林): 雪玉を押してクレバスに落とすと橋になる。かべにつけると動かせない(森を出なおすと元にもどる)
- 凍った川(雪の原生林): すべる氷の川を、岩にぶつけて止まりながら向こう岸の2か所の上陸地点をめざす
- マタギのじいさん(原生林の奥): つるはしをくれる。つるはしで氷山の入口の氷の壁をくだける
- 流氷(時間): 朝昼の流氷は氷山へ、夕夜の流氷は東の小島へ。乗っている流氷が流されると岸へもどされる
- 氷山の洞窟: 押した氷塊は氷の上をすべっていき、穴に落ちると道になる。3つの部屋(氷塊を止め木にする部屋・穴をうめる部屋・大きなすべる迷路)。天井からつららが落ちてくる(影に注意)
- 流れる流氷(外海): 決まった道を行ったり来たりしている。乗ると運ばれ、海の上で降りると落ちる
- シャチ: 外海の氷の上にいると、足もとに黒い影があらわれ、少しして氷を突き破ってくる。当たると海に落ち、しばらく穴があく
- すべる氷原・薄氷の迷路: 外海の大きなすべる氷原と、同じ所を2度ふむと割れる薄氷の道を抜けて、南東の王者のねぐらへ
- 氷原の崩壊: 流氷の王者を倒すと南から氷がくずれてくる。東のじぐざぐの氷の道を北の船着き場まで走ってにげる(追いつかれると王者のいた氷の上からやりなおし)。にげきると、観光船で岬と外海を行き来できる
- オーロラの丘(王者を倒すと入れる): 雪崩の斜面、全部の氷を一度ずつふむと宝が出る凍った湖、両がわがクレバスの尾根(地吹雪で押し流される)、朝昼だけの氷の橋と夕夜だけのオーロラの橋。山頂に裏のぬしアマノツル(夕夜)

### 火ノ島のしかけ
マップはこれまでの3倍ほどの広さ(溶岩の黒い浜 60×46、地獄谷 60×56、溶岩洞 44×58、火口のふち 60×52)。
- 溶岩流: ふだんは冷えた黒い岩で歩けるが、赤く光ったあと溶岩が流れる。流れているあいだは入れず、上にいると焼かれて手前へもどされる。流れる時間は2種類ずれている。タップで歩くと、冷えるまで手前で待ってから渡る
- 噴火と噴石: 山が鳴ったあと噴火して、噴石が降る。落ちる場所に影ができ、当たるとHPが減って少し動けない(黒い浜・火口のふち)
- 間欠泉: 噴き上がる瞬間に上に立っていると、向こう岸まで飛ばされる
- 噴気孔: ときどき蒸気が噴き出す。上にいると、HPが減って1歩押しもどされる(地獄谷の北の通り道は噴気孔だらけ)
- もろい足場: ふんで1秒たつと崩れて溶岩になる(しばらくするともどる)。立ち止まると落ちる
- 溶岩だまり: 岩を押しこむとふさがる
- 暑さ(地獄谷・溶岩洞・火口のふち): 歩くと暑さゲージがたまる。湧き水をAで調べると冷えて、たおれたときにそこで目をさます
- トロッコ(地獄谷): 黒い浜の高台の古道を抜けた先の動力室で動力を入れると動く。乗り場でAを押すと、線路の分かれ道しだいで行き先が変わる。分かれ道は2か所、切りかえレバーは谷のあちこちにある
- 溶岩洞: もろい足場の道、溶岩流の帯、間欠泉と岩押し。いちばん奥に火口のぬし。倒すと溶岩がせり上がってくるので、東の抜け穴を必死で走って地上へにげる(追いつかれると広間からやりなおし)
- 火口のふち(ぬしを倒すと入れる): 噴火がひんぱん。北東は溶岩流、北西は噴気孔、南東は崩れた足場。山の火が噴き出すところでたいまつに火をうつし(40歩で燃えつき、噴気をあびると消える)、四方の祭壇に灯すと、山頂に裏のぬしカグツチがあらわれる

### 珊瑚島のしかけ
- 白い砂浜(64×48): 南へのびる砂州はスコールの突風で西の海へ落とされる(岩の東がわにかくれる)。ヤシの木がゆれると実が落ちてくる。南の小島からはウミガメの背中に乗って西の島へ。干潮(昼と夜)だけ、北の入り江と干潟がつながる
- マングローブの森(60×56): カヌーで川を行く。船着き場でAを押すとこぎ出し、行き先は3か所の水門の向きで決まる。水門のレバーは船着き場ごとにある。ひみつの入り江のキノコの輪は、東のほこらの干潟へつながる
- 珊瑚礁のぬし: 川口の浮き桟橋に、夜にだけあらわれる。鎮めると、桟橋から海へもぐれる
- 珊瑚礁の海(64×60・海の中): 息のゲージがあり、泡のわく場所をAで調べると息をつげる(息が切れると最後の泡へもどされる)。海流に入ると珊瑚にぶつかるまで流され、出口のある場所で止まれる流れをえらぶ。サメの通り道(ふれると手前へもどされる)、ぱくりと閉じるシャコ貝、海溝のクラゲ。いちばん深い所に裏のぬしニライと宝箱

### 黄泉ヶ原のしかけ(終点)
- 提灯の灯: 黄泉ヶ原の探索先はどこも暗く、提灯の火は歩くほど小さくなって、見える範囲がせばまる。灯籠をAで調べると火をもらえる。火が消えると、最後の灯籠へもどされる
- 人魂: 決まった道をただよっている。ふれると火をすいとられ、手前へもどされる
- 彼岸花の原(64×52): 北の墓原の人魂のあいだをぬって六文銭のかけらを拾う。南の「ふり返らずの小道」は、北(うしろ)を向くと入口へもどされる。行き止まりに入ってもやりなおし
- 忘れ川のほとり(64×56): 流し灯籠に乗って中州へ渡り、3つ目のかけらを拾う。3つそろうと渡し舟が出る
- 川の向こう(44×40): あの世に近く、左右がさかさまになる(十字キーで歩く)。坂の入口にひらさかの番蛇
- ひらさかの上(40×76・番蛇を鎮めると入れる): 朽ちた石段(崩れる)、風の尾根、人魂の原、千引の岩が転がる沢を登る。とちゅうの桃の木から桃を3つもげる。坂の上の待ち灯にふれると、黄泉の黒い手が坂の上から追ってくる。ふもとの鳥居まで走ってにげ、Aで桃を投げると追っ手を押しもどせる。にげきったあと、坂の上の灯の下で裏のぬしトコヨが待っている

### レベル
歩くと出会う回数が多いので、野生は元の1.25倍、ぬしとライバルは1.2倍、裏のぬしは1.15倍にしている(`OW_LV`)。

## 作り方

- ゲーム本体: `src/game.html`
- 歩けるマップ: `src/parts/overworld.js` の内容が `src/game.html` に入っている
- アプリ版を作る: `python3 tools/build_app.py src/game.html .`(`index.html`・`sw.js`・`manifest.webmanifest` ができる)
- アイコン: `python3 tools/make_icons.py icons`
- イラストの埋めこみ: `python3 tools/embed_art.py`

セーブは「ジェンガルア配合録」とは別の場所(`michikusa-save-v1`)に保存されます。
