# Phase 0 描画の試作(tech-artist 技術美術班)

試作ページ: `tools/proto/render.html`(`cd diorama && python3 -m http.server 8102` → http://localhost:8102/tools/proto/render.html)
スクショ: `docs/shots/phase0_render_*.png`(撮り直しは `node tools/proto/shoot_render.cjs [名前の一部,…]`、数字は `docs/shots/phase0_render_stats.json`)

## 作ったもの(`src/render/`、ゲーム本体でそのまま使える部品)

| ファイル | 中身 |
|---|---|
| `renderer.js` | レンダラー・シーン・光。主光 = 左上奥(卓上ランプの方向)からの暖色の平行光 + 影、空色/机色の半球光、カメラ右手前からの青みの補助光(影なし)。画質 低/中/高 と `autoQuality()`(中で 2.5 秒測り、52fps 以上かつ高 DPI なら高、30fps 未満なら低)。`info.autoReset=false` で、影の描画と後処理も含めた1フレーム分の `renderer.info` を出す |
| `camera.js` | 画角 25° の透視投影、見下ろし 52°。Q/E で 90° ずつ回る(指数補間)。ドラッグで向き・角度とも ±15°(ダブルクリックで戻す)。注視点は主人公を追う。画面の縦横から距離を決め、横は約13マス・縦は約19マスが見える。建物の中では 0.8 倍に寄る |
| `tiltshift.js` | 1回の全画面パスで: ティルトシフト(ボーゲル円盤 18 点、ピント帯は主人公の画面の高さ、奥は手前の 1.25 倍ぼかす、ピント帯の中は1点だけ読む)+ 高のみ深度8点の SSAO 近似 + ACES・彩度 1.08・ごく弱い周辺減光・ディザ |
| `cutaway.js` | 主人公とカメラのあいだをふさぐ壁・木を、インスタンスごとの `aCut`(世界のY)で根もとから切る。切り口は裏面を「生成り + 黒インクの斜線」で塗る = 説明書の断面図。影も同じ高さで切れる(`customDepthMaterial`)。描画回数は増えない |
| `diorama.js` | マップ JSON → InstancedMesh。タイルは上面だけ面取りした形(まわりが同じ高さなら側面なしの 14 三角形、段差のきわだけ 30 三角形)、色はマスごとにゆらし、塗りムラは共有ノイズ1枚を世界座標で引く。草の房(三角形3枚)と花、樹脂の水、壁(本体・腰板・梁・窓・まぐさ)、木(切り抜き可)、家具は階ごとに1メッシュ、村人の駒は1つの InstancedMesh。台の断面(草/土/発泡材/合板/額縁の地層)、カッターマット(方眼・目盛り・角度線)、机、巨大な卓上ランプ・定規・ペン立て・ピンセット・ランナー・塗料びん |
| `buildings.js` | 屋根(切妻 + 瓦の段 + 棟 + 煙突、時計塔は文字盤4面と四角すい屋根)。中に入ると屋根がばねで「ふわっと」持ち上がり、画面の右へずれて少し傾き、影を落とすのをやめる。手前の壁は断面を見せて切れ、カメラが寄る。2階建ては、1階にいると2階(床・壁・家具)が手前の板からめくれて右上奥へ浮く「分解図」になり、2階にいると2階の手前の壁だけ切れる。外で屋根の陰に入ると、その屋根は消えて中が見える |
| `materials.js` | 共有の塗りムラ(256² のノイズ1枚)、`paint()`(断面つき切り抜き)、面取りタイル/箱、頂点色でまとめる道具 |

操作: 矢印キー(または画面の十字)で1マスずつ歩く(`core/grid.js` の `canStep`・階段を使う)、Q/E と ⟲⟳ で回転、ドラッグで傾き、1/2/3 で画質。`?at=l,x,z` で始める場所、`?q=low|mid|high` で画質固定(なしなら自動選択)。

## 決めたこと

- 1マス = 1、高さ1段 = 0.5、1階ぶん = 1.5。マス (x,z) の中心が世界 (x,*,z)
- 切り抜きは「透かす」ではなく「根もとで切って断面を見せる」。半透明の並べ替えが要らず、影も正しく、説明書の断面図と同じ絵になる
- 2階建ての「床がはがれる」は、ちょうつがいで立てると画面の外へ出てしまったので、**説明書の分解図**(手前の板から順にめくれて、2階まるごと右上奥へ浮く。屋根はさらに上)にした
- 外で屋根の陰に入ったら、屋根を半透明にせず消す(半透明の瓦の筋が汚く見えたため)
- 卓上ランプは影を落とさない(光源そのもの。かさが村に大きな影を落としていた)
- 高の SSAO は深度テクスチャを読むので、高だけ MSAA を切り、ピクセル比2で補う。中は MSAA 4

## 課題

1. headless の SwiftShader では fps が測れない(0〜29)。実機(iPhone・中級 Android)で中/高の fps と `autoQuality()` のしきい値を確かめる必要がある。重いのはティルトシフトの 18 点読み(全画面の約6割)
2. 60×48 のエリアではタイルが約 2.3 倍になる。縦画面はほぼ全体が映るので、地面を 8×8 マスの塊に分けて視錐台で間引く(描画 +10 回程度)と三角形を抑えられる
3. 壁の手前切りは「視線の近く」と「入った建物の手前の辺」だけ。曲がった壁の内角や、2つの建物のすき間などは、まだ切り残しが出ることがある
4. 時計塔は箱 + 文字盤の仮の形。ゼンマイ時計塔の断面表示(5-4)は別に作る
5. 主人公と村人は仮の駒。魔物の glb(parts.glb)を載せたときの三角形を、上の表に足して見積もる(1体 2k 三角形 × 画面 15 体でも +30k で収まる)
6. 窓の箱は壁を貫いているので、壁を切ったとき窓も一緒に消える(断面に窓は出ない)。気になるなら窓だけ切り口の色を変える
