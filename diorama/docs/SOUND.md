## 主題「ネジマキのうた」

ハ長調・4/4・16小節(A 8小節 + B 8小節 = 64拍)。オリジナル。

- A: ゼンマイを巻くように上がる動機(ソ・ド・ミ)で始まり、いったん下りて「レ」で問いかけ、2回目は高いドへ跳んで落ち着く
- B: 高い所(ラ・ド)から歌い出し、5小節目からもう一度上がってレまで届き、半終止で A の頭へもどる(ループの継ぎ目が自然につながる)
- 和音: A = C Am F G C Em F-G C / B = F G Em Am Dm G C-F G
- 短調の曲は `minorize()` で作る(ハ短調: Cm Ab Fm G Cm Eb Fm-G Cm / Fm G Eb Ab Ddim G Cm-Fm G)。ミ・ラ・シは、その時の和音にふくまれていればそのまま、なければ半音下げる(G の上ではシ♮ のまま = 和声的短音階の響き)

## ループの継ぎ目

- 曲は「拍」の単位で先読み(0.3秒先、画面が裏のときは1.5秒先)して予約する。ループの頭は拍の時刻を足しつづけるだけなので、すき間ができない。残響と減衰中の音は継ぎ目をまたいで鳴りつづける
- 前奏のある曲(battle・nushi・boss)は、前奏を1回だけ鳴らし、ループは前奏の後から
- どの曲もループの長さは小節(4拍)の倍数。時計塔は4拍の倍数なので、継ぎ目で振り子がとばない
- 測定で、ループの終わり4拍前から8拍を書き出し、継ぎ目の前後1拍の 50ms の窓の最小の RMS が全体の中央値から何 dB 落ちるかを見る(18dB 以上で「切れ」)。全曲 4.7〜11.8dB(フレーズの終わりの休みの分)で、切れはない

## 音の通り道とうるささ対策

```
曲 → 曲のフェード → BGM音量(5段階 × 0.42)→ ダック(ジングル中 0.18)→ master ─┐
ジングル ─────────→ BGM音量 ────────────────────────────→ master ─┤→ コンプ(-14dB 2.5:1)→ リミッター(-2.5dB 20:1)→ 出力
効果音 → 名前ごとの補正 → 効果音音量(5段階 × 0.8)──────────→ master ─┘
残響: BGM 用(2.6秒)・効果音用(1.2秒)。合成したインパルス
```

- 音量の5段階: 0 / 0.16 / 0.36 / 0.64 / 1(耳の感じ方に合わせた曲線)。既定は 3
- 曲の RMS を -21 dBFS(音量最大)にそろえた。ジングルは -19、効果音は UI -28〜-32、足音 -33〜-39、ギミック -24〜-28、打撃 -20〜-21
- 高音の刺さり: 4kHz より上のエネルギーを測る。いちばん多い battle・boss でも全体の -23dB。オルゴールの高い部分音は短く消し、金管のフィルターは鳴り始めだけ開く
- 1音ごとに強さを ±6% ゆらす(決まった乱数。書き出すたびに同じ音)
