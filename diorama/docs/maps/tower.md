# ゼンマイ時計塔 設計図(tower)

- 大きさ: **25×25 × 6階**(中心 (12,12)。DECISIONS: 90°回転がマス目に合うよう 24 ではなく 25)/ アクセント: 朱 `#d2462d` / BGM: tower(チクタクの打楽器と金管)
- ルール: **つなぐ(連動)**。文字盤の針で外周の床(半径4〜8の輪)が90°回る — これはつみき野の「まわす」の再登場。**新しいのは、ピンセットで歯車を軸にはめると、別の階の床もいっしょに回ること**(1:1 / 大きい歯車は 2:1 / 外せば切れる)
- 塔はピンセットのあと(村の塔のホールで扉の歯車をはめて入る)。目安 20分。ボスまで最少操作 **8回**(下見)

## 1. 階のつくり(どの階も同じ骨組み)

```
   中心から半径0〜3   : 文字盤の床(回らない)。中心 (12,12) が文字盤(調べると針が進む)
   半径4〜8           : 外周の床(輪)。はじめは壁で、決まった向きにだけ通路(スポーク・弧)がある。針1つで90°時計回り
   半径9〜11          : 外の回廊(回らない)。斜め45°ごとの仕切り壁で4つの区画(北・東・南・西)に分かれる
   半径12             : 外壁
   rim(角度, 半径)    : 北を0°、時計回り。マスは (12 + round(半径×sin), 12 − round(半径×cos))
                        例: rim(0,11)=(12,1) 北 / rim(90,11)=(23,12) 東 / rim(180,11)=(12,23) 南 / rim(270,10)=(2,12) 西
```

区画どうしは仕切り壁で切れているので、**区画から区画へ移るには、輪の通路で中心を通る** しかない。これが「輪の向きで行ける区画が変わる」の正体。

### 3-1. 2階 → 3階(習う): はめる前に回した分も数に入る

- 2階に北から着く。r1 はスポーク北・東。3階の r2 は弧(南→西→北)で、**r2 が 0 か 2 のときだけ** 3階の南(着く所)と北(上り階段)がつながる。はじめは 1
- 2階の出口(南の階段)へ出るには、r1 が 1(東・南)か 2(南・西)
- 歯車をはめてから r1 を **1回** 回すと、r1=1・r2=2 で両方そろう。はめる前に回すと、その分 2階だけずれる(回し直せばよい。詰まない)
- 看板「歯車でつながった階は、いっしょに回ります」

### 3-2. 4階 → 5階(試す・組む): 大きい歯車と付けかえ

- 4階の r3 を回すと、大きい歯車を通して r4(5階)が **2回に1回** 回る(歯車の中の印 `gp` が半回転ずつ進む)
- 5階には文字盤がない。**5階をそろえるには4階で回すしかない**。ところが4階の出口(東の階段)は r3 の決まった向きでしかひらかない
- 解き方: 4階で r3 を回して r4 をそろえる → **大きい歯車を軸から外す**(5階はそのまま残る)→ r3 だけ回して4階の東をひらく → 上る。「外せば、下の階だけ回せる」= 付けかえの考え方
- 振り子: 4階の外の回廊に4本、`period: 4`(BGM 4拍で1往復)。振り子のマス rim(deg, 9..11) は、拍の 2/4 の間ふさがる。ソルバーでは「待てば通れる」とみなす

### 3-3. 6階(ボス)

- 外周の輪はなく、中心に直径9の **回転台の対戦台**。北の階段 (12,1) から着いて、南へ歩くとトケイモリ (12,9) が起きる
- 戦闘の台の回転(前列と後列の入れかわり)は DESIGN.md §4-8
- 勝ったあと、中心の文字盤を調べるとエンディング

## 7. ソルバーで確かめること

- ピンセットなし: 1〜2階だけ。ありで、全宝箱・全階段・ボスに届く。どの状態からも入口 (12,23) に戻れる
- 「大きい歯車を外さないと 5階→6階へ行けない」が成り立つこと(付けかえが必須になっていること)。成り立たなければ 4階の `start` か出口の向きを変える
- 宝の部屋の物は、別の階へ運んでもよい(階段を上り下りしても持ったまま)。置かずに塔を出たら元の場所へ
