## 3. 解き方(最少の操作)

抽象モデル(陸 = 点、台 = 腕の向き)の幅優先で確かめた手順。`→` は歩く、`[ ]` は操作。

1. R0 → 台Aの腕に乗る → 中心へ。**[A を回す ×2]**(乗ったまま回る。腕が北へ)→ R3
   - (A を1回なら西 R1、3回なら東 R2)
2. R3 → 台D(南の腕)→ D の東の腕 → R5
3. R5 で **[C を回す ×2]**(k1→k3: 腕が西・北)→ 台Cに乗って北へ → R8
4. R8 で **[E を回す ×1]**(腕が北・南。E は R7 と R8 をつながなくなる)
5. R8 → C → R5 → D(東の腕から西の腕へ)→ R4
6. R4 で **[D を回す ×1]**(k3: 南・西・北)。D の東の腕がなくなり、R5 への道は閉じる。かわりに北の腕がひらく
7. R4 → D → 北 → R6 → 台E(南の腕から北の腕)→ R9 ゴール

合計 **6操作**: A×2、C×2(R5 から)、E×1(R8 から)、D×1(R4 から)。

**段取りのねらい**

| 段 | どこで | 覚えること |
|---|---|---|
| 習う | 台A | 腕が1本しかない台は、乗ったまま回して出口を選ぶ |
| 試す | 台B(R1 のハンドル) | 1回回すと R1→R7 がつながる(B:東西→南北)。宝のある北西へ |
| 試す | 台C(R2 のハンドル) | 回すと自分の側(南)の腕が動いて、乗れなくなることがある → ぐるっと回りこむ |
| 組む | C・E・D | ①Cを「R8 へ行く役」に使う ②遠い陸から E をそろえて、別の道から乗る ③最後に D を回すと来た道が閉じ、北がひらく |

**詰まないこと**: 回転台は4回回せば元どおり。ハンドルのある陸からは、来た道をもどす向きに回せる。台Aは腕1本で、主人公が最後に降りた陸を向いたまま残るので、来た道を逆にたどれば必ず乗れる。抽象モデルで、到達できる 1540 状態すべてから入口に戻れることを確かめた(本番のソルバーでも確かめる)。

各陸への最少操作(抽象モデル): R1 1 / R2 3 / R3 2 / R4 2 / R5 2 / R6 3 / R7 2 / R8 2 / R9 **6** / R10 2 / R11 3。

## 4. カメラ回転の練習

- 宝箱 (12,37) は積み木の山 (11..12, 38..40) の北側、宝箱 (56,35) は山 (55..56, 36..38) の北側。はじめのカメラ(南から見る)では山にかくれて見えない。**北・東・西のどれか1方向から見たときだけ見える** ように、山の高さを4にする
- R7 の丘 (14..20, 4..9) の北の裾に、裏からだけ見える宝(R7 の宝箱 (3,3) の代わりに置いてもよい)
- ご隠居の台詞「積み木の裏は、カメラを回すと見えるぞい」
