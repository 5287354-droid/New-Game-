# ランプの森 設計図(forest)

- 大きさ: **56×48**(たたき台と同じ)/ アクセント: 藍 `#2e4a8b` / BGM: forest(低いオルゴールと鈴)
- ルール: **てらす(光と影)**。森の外の巨大な卓上ランプの向き(東・真上・西)で影が動く。**谷は、影の落ちたマスだけ歩ける**
- ランプの向きは森全体で1つ。ランプ台(`*`)に乗って調べると **東(0) → 真上(1) → 西(2) → 東(0)…** の順に変わる。はじめは **西(2)**
- 光の当たる谷に入ると、直前の足場に戻る(痛みなし)
- 目安: 15分。ぬしまでランプ操作 **8回**(たたき台は、ぬしに届かなかった)

## 2. 影の規則(grid.js の直し)

- 影を落とす物 `caster` は `{x, z, angle, len, wide}`。**影は幹のマス (x,z) ではなく、幹の1つ南の列 z+1 から wide 列ぶん** 落ちる(ランプが作業台の奥=北の高い所にあるので、影は手前にずれる)。光と反対の向き(東の光なら西)へ、幹の列から len マス
- これで幹が影の橋の入口をふさがない。幹のとなり(南)のマスが橋の始まりになる
- 大枝のアーチは、真上の光(1)のとき、足もとの範囲がそのまま影になる
- 影は **実行時に casters から計算** する(ピンセットで切り絵の木を立てると影が増えるため)。たたき台の `shadow` の固定リストはやめる
- 地面の木陰(飾りの木)は歩くのに関係ない。影の魔物の出る場所には使う

**詰まないこと**: 影の橋でしか出入りできない陸(F1S・F1N・柱・F2・I1・F3)には、すべてランプ台がある。ランプは3つの向きを順に回るので、どの陸からでも、来た橋の向きに戻せる。I2・I3・くぼみ・影の巣にはランプ台がないが、行きと帰りが同じ向きの橋なので、何もしなければ戻れる。下見の幅優先で、15 状態すべてから出口へ戻れることを確かめた。

## 8. ピンセットで後から行ける場所

- 切り絵の木(タグつき)は F0 の北西 (5,6)。つまんで、谷を2つ越えて F2 の北のはしの台座 (41,2) まで運ぶ(持ったままランプを変え、影の橋を渡る。**てらす × はめる**)

## 9. 魔物

DESIGN.md §9。影の魔物(オリガラス・ホタルビン)は **今の影の上** にだけ立っている。ランプを変えると消える/現れるので、谷の影の橋の上にいる影の魔物は「よけるか、戦うか」の選択になる。光の魔物(フェルトン)は光の当たる地面だけ。
