# ネジマキ村 設計図(village)

- 大きさ: **48×40**(たたき台の 40×32 から広げる。理由: 8つの建物を、塔を中心に広場をかこむ形で置き、裏庭と小川の寄り道を入れるため)
- アクセント: 山吹 `#e0a526` / BGM: village / ルール: **めくる(建物の中)**
- レベル(階): 0 = 地上、1 = 2階(自宅の屋根裏・村長の家・宿屋)、2 = 物置の屋根裏(カメラの隠し棚)
- 時計塔の中(6階)は別エリア `tower`。村の塔の建物は「入口のホール」だけ

## 2. 主な道筋

1. 自宅 (6,8) を出る → 道 (6,9)〜(6,11) → 広場 (14..30, 10..23)
2. 工房: 広場の東 → 橋 (31..32, 14..15) → 戸口 (35,14)。親方 (40,13)
3. 村長の家: 広場の北東 (30,9) → 橋 (31..32, 9) → (33..39, 9) → 戸口 (39,8)
4. 南の大通り (22..25, 21..38) → 出口 (22..25, 38) → 作業台
5. 時計塔のホール: 広場の中央、戸口 (23..24, 19)。中の出口 (23..24, 12) は `openTower` まで閉じている

## 8. ソルバーで確かめること

- `wokeUp` だけで: 自宅・工房・よろず屋・村長の家(2Fまで)・宿屋(2Fまで)・図書小屋・物置・裏庭 のすべての `$` に届く
- 屋根裏の棚は「カメラ北向き」の条件つきで届く(ソルバーではカメラを状態に入れず、条件として記録)
- `gotTweezers` なしでは塔の1階に入れない / ありなら `v_gear` → `v_tower_axle` で入れる。歯車を取ったあと置かずに村を出ても、工房に戻る(詰まない)
