## 0. ひとことで

> **「塗装した木と紙の模型の上に、つやのあるソフビ人形が立っている。それを組立説明書が案内する」**

3つの層を、**質感で分ける**のがこの作品の画風のいちばんの決まり。

| 層 | 質感 | つや | 彩度 |
|---|---|---|---|
| 魔物(人形) | ソフトビニール + 素材の表面 | **あり**(クリアコートのやわらかいハイライト) | いちばん高い(差し色) |
| ジオラマ(模型) | 塗装した木・紙・粘土・樹脂 | **なし**(マット。水の樹脂だけ例外) | 中くらい |
| 机と道具(現実) | 本物のカッターマット・定規・ランプ | 素材なり | 低め・ぼける |
| UI(説明書) | 紙とインク | なし | 生成り + 黒 + アクセント1色 |

この順で「目が行く」ようにする。魔物がジオラマに溶けたら、それは画風の失敗。

## 1. 魔物

### 1-1. 採用する質感: **A+ 案(A案ベースの折衷)**

工房の A案(つやソフビ)を土台に、B案から「素材の表面の強さ」と「ふちの薄いドライブラシ」だけをもらう。理由は `docs/ART_REVIEW.md` §1。

`createMonsterMaterial` の値(`STYLES` に `'A+'` として足し、ゲームはこれを使う):

| 値 | A案 | B案 | **A+(採用)** | ねらい |
|---|---:|---:|---:|---|
| rough(下地) | 0.32 | 0.70 | **0.38** | ソフビの下地 |
| coat(クリアコート) | 0.75 | 0 | **0.60** | 地面(マット)から浮かせる |
| coatRough | 0.28 | 0.60 | **0.30** | ハイライトは丸くやわらかく。点光にしない |
| sss(ふちの透け) | 0.42 | 0.08 | **0.35** | ソフビの「少し透ける」 |
| surf(素材の表面) | 0.55 | 1.5 | **0.90** | フィールドの距離で、石・布・紙の差が分かる強さ |
| accentSat | 1.30 | 0.92 | **1.15** | 差し色ははっきり。ただしジオラマの屋根より上に出すぎない |
| edge(ふちの明るさ) | 0 | 0.55 | **0.20** | 塗装の手ざわりを少しだけ |
| tinMetal | 0.35 | 0.55 | **0.45** | |
| sheen(布の起毛) | 0.35 | 0.8 | **0.60** | |
| cavity(くぼみの暗がり) | 0.15 | 0.55 | **0.35** | 縫い目・打ち出しを読ませる |
| 目のひとみ | 水色 `#5fe0ff` | 琥珀 | **水色 `#5fe0ff`** | 琥珀は金の差し色・茶の地面に溶けた |

**素材ごとの上書き**(FRAG_SURFACE の中で。マテリアルは1つのまま):

| 素材 | coat | rough | そのほか |
|---|---:|---:|---|
| ブリキ | ×1.0 | 0.30 | 打ち出しのくぼみ。金属感 0.45。つや最大 |
| 水(インク・ガラス) | ×1.2 | 0.15 | ぬれたつや + にじみ。ガラスびんは透けを 0.6 |
| 火(ロウ) | ×1.1 | 0.30 | とろみ + 垂れ筋。**炎の部分は発光**(下の 1-6) |
| 石 | ×0.6 | 0.55 | ざらつき + ごま。**石だけは「つやの薄い塗り石」**に見えてよい |
| 布 | ×0.5 | 0.60 | 起毛 sheen + 縫い目。つやは「表面に薄くニス」程度 |
| 紙 | ×0.5 | 0.55 | 繊維 + **折り目(面の切りかえ)**。なめらかな曲面にしない |

> 「全員ソフビ」の上で、素材の差は **形(折り目・縫い目・打ち出し)と表面**で出す。つやを0にして別画風にしない。

### 1-2. 色の決め方

1体の色は **地の色(body) 1 + 差し色(accent) 1** の2色だけ。目は規格の色。3色目は使わない(素材の表面の模様は色数に数えない)。

- **地の色**: 素材の色の範囲から選ぶ(下の表)。面積の 70〜90%
- **差し色**: 彩度 60% 以上。面積の 10〜30%。決め手の形(1-4)に必ず差し色をのせる
- **地面とのちがい**: 出るエリアの地面の色と、明るさで 15% 以上、または色相で 40° 以上はなれる。**草(色相 70〜140°・彩度 30% 以上)の地の色は、野外に出る種には使わない**
- 20種の地の色は、明るさ・色相で散らす。同じ素材の種は、明るさか色相をはっきり変える

| 素材 | 地の色の範囲 | 例 |
|---|---|---|
| ブリキ | 青みの銀〜真鍮〜塗装缶の色。彩度 ≤ 25%(塗装缶なら ≤ 50%) | `#b8c4cc` `#c7cfd6` |
| 紙 | 生成り・白・墨・色紙。色紙は彩度 ≤ 55% | `#f1e9d6` `#2c2b33` |
| 水 | 藍・群青・水色。透けるもの | `#33508f` `#9fd0d8` |
| 石 | 灰・黄土・赤土。彩度 ≤ 25% | `#9a958b` `#7d786e` |
| 布 | どの色相でもよい。彩度 30〜60%(フェルト・木綿の色) | `#8c6db0` |
| 火 | 朱・橙・生成りのロウ・素焼きの土 | `#f2ead8` |

**予約された色**: 紫〜すみれ(色相 250〜290°・暗い)は **影の色**として カゲボウシ と森の影に使う。ほかの種の地の色にしない(差し色ならよい)。

### 1-3. 目の規格(全種共通・変えない)

| 項目 | 規格 |
|---|---|
| 形 | 暗いガラス玉(球)。まぶた・まつげ・眉は **つけない** |
| 大きさ | 半径 0.075(体の高さ 1 に対して)。ぬしも同じ比率(体ごと拡大) |
| 位置 | 左右 ±0.135、左右同じ高さ。頭の正面(+Z)に、**半径の 60% 以上を埋める** |
| ひとみ | 正面を向いた所が光る輪(水色 `#5fe0ff`)+ 黒いひとみ。全種同じ |
| ハイライト | 画面の左上に白い点 1つ + 右下に小さな青い照り返し(向きは視点空間で固定。全種同じ) |
| 見える範囲 | 正面から左右 ±60° で **両目** が見える。±100° で片目が見える |
| 口 | なくてよい。つけるなら **刻んだ線 1本**(ブリキシのかぶとのすき間のように、形の一部として)。歯・舌・笑った口の形は禁止 |

目が頭のふちから飛び出して、横から「虫の目」に見えるのは不可(コロイシで起きている)。

### 1-4. シルエットの規則

1. **決め手の形**を1種に1つ。体の輪郭から外へ出て、64px のシルエットの面積の 15% 以上を占める。決め手には差し色をのせる
2. 64px の判定は3枚で行う: **正面ななめ(右前 35°)・真横・フィールドのカメラ(見下ろし 52°)**。見下ろしで決め手が隠れる形は不可(帽子のつばで全身が隠れる、など)
3. **同じ型の種どうし**は、64px のシルエットの重なり(IoU)を 0.75 以下にする。工房は `tools/forge_shots` に IoU を測って一覧に出す機能を足す(どの2種でも 0.75 を超えたら赤)
4. 体の高さ: 正面から見た高さが **0.55 以上**(へびの型は頭を持ち上げる)。小さすぎてフィールドで点になる種を作らない
5. 「頭を胴の上に積んだだけ」の雪だるまの形を、3種以上に使わない(いまは まる・しずく の6種がこの形。§ART_REVIEW 2-2)
6. 型の胴は、名前どおりの形を守る: **しずく = 1つのしずく形**(下がふくらみ、上が細い)。2つの球を重ねた形はしずくではない

### 1-5. 色違い(きらり)

- 地の色を **色相で 60° 以上、または明るさで 25% 以上** 変える(両方なら尚よい)。64px で通常と見分けられること
- 差し色は工房の式(色相 +151°・少し明るく)でよい
- 真珠色のうつろい + ラメは全種共通。ラメの密度は変えない
- 白〜生成りの種(ペラリ・ワタボウシ・ハリボテ・ロウソクン)は、きらりで **白に近い色を使わない**(いまハリボテは生成り→白で見分けにくい)

### 1-6. 光る所

- 光ってよいのは **目のひとみ・炎・ホタルビンの光・★3 金つぎ** の4つだけ
- 炎(マッチボウの頭・ロウソクンの芯・ヒバチネコの炭)は、外側の色 → 内側の明るい黄の2段 + 発光。不透明な円すいや球のままにしない
- ブルーム・光のにじみは使わない(後処理にブルームを入れない)

### 1-7. おさがりパーツの塗り直し

| 場合 | 塗り方 |
|---|---|
| 生まれつきでないパーツ(★1〜) | スロットごとに子の色へ: body スロット → 子の地の色、accent → 子の差し色。表面は **子の素材**(紙の子なら繊維と折り目) |
| ★2 なじみ | 上に加えて、つぎ目に銀の輪 + ふちの銀の光 |
| ★3 金つぎ | ひびに金がしみて発光 + つぎ目の金の輪。**戦闘の寄りで、どの素材の上でも見える**こと(A案の紙の上で弱かった) |
| きらりの親から | 親のきらり色のまま。表面だけ子の素材 |

- 形は変えない(親のパーツの形そのまま)。大きさも変えない。ソケットに合わせて回すだけ
- ★2/★3 の線は、パーツの原点からの距離で決める(工房の実装のまま)

### 1-8. 三角形の予算

| 単位 | 上限 |
|---|---:|
| 胴 / 頭 / 背中 / しっぽ | 1,000 / 1,300 / 900 / 700 |
| 1体(おさがりのどの組み合わせでも) | 4,000(実測の最悪 3,418) |
| フィールドの魔物(画面内) | 15体 × 4,000 = 60,000 まで。ジオラマ 9万と合わせて 15万以内 |
| 戦闘(6体) | 24,000 + 対戦台 |
| 図鑑のビューア | 1体なので上限なし。ただし同じ形を使う |

三角形を足すなら、**シルエットに効く所**(決め手の形・頭のふち)に使う。見えない底面・胴の中に埋まる部分は削る。

### 1-9. 形の作り方(Blender)

- 角は小さく丸める(ベベル 1〜2 段)。ソフビの型抜きの「ふくらみ」を出す
- 薄い板(紙・羽・つば)は厚み 0.02 以上。真横から消えない
- 布は中心線に縫い目(シェーダー)。紙は面の切りかえ(折り目)を形で作る
- 胴の下に、ソフビ人形らしい **足の裏の平ら** を作る(台に立つ)

## 2. ジオラマ

### 2-1. 地面

- **マット**(roughness 0.85〜0.95、つやなし)。塗りムラ(共有ノイズ)を 3〜6% の明るさで
- 草: 地の色 `#7c9f4b` 前後。**彩度 45% まで**(ライムに見せない)。草の房は濃い緑で、黒い点にしない
- 草の上には **マス目の線・点を出さない**。マスは石畳・板の床・タイルの所だけ、継ぎ目の線で見せる
- 石畳は、1×1 と 2×1 の石を混ぜ、継ぎ目を半マスずらす。継ぎ目は地の色より明るさ −15% の線(点は打たない)
- 土・粘土: `#a47a50` `#b8875a`。指でならした跡のような、ゆるい凹凸
- 水: 樹脂。中央が濃く、岸ぎわが明るい2段。つやの筋を1本。地の色 `#4c9fbd` から彩度 −20%

### 2-2. 建物

- 壁: 漆喰は **暖かい生成り**(`#eadfc8`)に見えること。青い補助光で灰色に沈んだら、壁の色を暖かく寄せる
- 柱・梁: 塗った木 `#5a3f2c`。角にベベル
- 屋根: **くすんだ5色** から選ぶ(下表)。彩度 ≤ 55%、明るさ 35〜55%。紫・赤紫・水色の屋根は使わない(紫は影の色、§1-2)
- エリアのアクセント色の屋根は、エリアに **1棟だけ**(村なら山吹の屋根を時計塔の近くに1つ)

| 屋根の色 | 値 |
|---|---|
| 朱土 | `#a9533d` |
| くすんだ藍 | `#4f6d8f` |
| 苔 | `#6c8f4f` |
| 黄土 | `#b8873a` |
| 焦茶 | `#6a452d` |

- 切り抜きの断面: 生成り `#f1e6cc` + 黒インクの斜線(45°、間隔 4px 相当)。説明書の断面図と同じ絵に

### 2-3. 作業台と巨大な道具

- 「現実」の層。ジオラマより **彩度を低く** し、ティルトシフトでぼける位置に置く
- カッターマット: 濃い青緑 + 白い方眼。彩度は今より −20%(ジオラマより目立たせない)
- 定規・ピンセット・ペン立て・塗料びん・ランナー: 本物の素材感(金属・透明樹脂)。ここだけはつやがあってよい
- 卓上ランプ = 主光の向き(左上奥)の理由。画面に入るときは、かさの内側が明るい

### 2-4. 光

- 主光: 左上奥(`LIGHT_DIR`)の暖色。影はやわらかめ
- 環境: 空の青(上)と机の木(下)の半球光
- 補助光: カメラ右手前の青み、弱く。**魔物の右下の青い照り返しは、これと同じ向き**
- 時刻(朝・昼・夕・夜)は主光の色と強さだけ変える。色つきの霧をかけない
- ティルトシフト: ピントの帯は **主人公を中心に画面の高さの ±18%**、そこから 18% かけてぼける。最大のぼけは縦画面で 6px(CSS px)。ぼけに粒(円盤の点の模様)を出さない

### 2-5. エリアの色

| エリア | アクセント | 地面の主な色 | 気をつけること |
|---|---|---|---|
| ネジマキ村 | 山吹 `#e0a526` | 石畳の生成り + 草 | 屋根をくすませる |
| つみき野 | 黄緑 `#9cc43a` | 草 + 積み木の原色 | 積み木は原色でよい(この野だけの例外)。魔物の地の色と重ねない |
| ランプの森 | 藍 `#34508a` | 暗い草 + 影 | 影の中で魔物が消えないよう、魔物のふちの透け(sss)を残す |
| ゼンマイ時計塔 | 朱 `#c8462c` | 板の床 + 真鍮 | 真鍮とブリキの魔物が溶けないよう、床は暗い板 |

## 3. UI(プラモデルの組立説明書調)

### 3-1. 決まり

| 項目 | 規則 |
|---|---|
| 地 | 生成りの紙 `#F4F1EA`。紙の繊維のテクスチャは使わない(平らな色) |
| 線 | 黒いインク `#1A1714`。太さ 2px(小さい部品は 1.5px)。**影・光のにじみ・ぼかし・グラデーションは使わない** |
| 角 | 丸め ≤ 4px。ボタンも枠も同じ |
| 文字 | 太いゴシック(Noto Sans JP 700〜900)。数字は Barlow Condensed 600〜700 |
| アクセント | エリアの色を1色。面積は画面の 10% まで。選んでいる項目の塗り・番号の地・進み具合のバーにだけ |
| 選んでいる状態 | アクセント色の塗り + 黒の枠。光らせない・浮かせない |
| メニューの枠 | ランナー(プラモの枠)の形: 外枠の太い線 + 項目をつなぐ細いゲート + 角の丸いゲート跡 |
| 項目の記号 | パーツ番号 A-1, A-2 …(画面ごとに A, B, C …) |
| 手順 | ①②③ の丸数字。矢印は説明書の太い矢印(黒い三角の頭) |
| 切る・折る・はめる | 切る = 黒の破線、折る = 一点鎖線、はめる = 矢印 + 「カチッ」の小さな線 |
| 断面 | 生成り + 45° の黒い斜線(ジオラマの切り抜きと同じ) |
| アイコン | 黒の線画。塗りはアクセント色か黒だけ。絵文字は使わない |

### 3-2. 画面ごと

- **図鑑 = パーツ一覧**: 見開き。左に3D のビューア(魔物は forge の形と A+ の質感で、背景は生成りの紙)、右に部品表(頭・背中・しっぽの部品番号と効果)
- **配合 = 組み立て手順**: ①親を2体置く ②受けつぐ部品を選ぶ(破線で囲う)③子にはめる(矢印)。子の完成図は3D
- **戦闘**: 下に指示の紙。HP は Barlow Condensed の数字 + 黒い枠のバー(中身はアクセント色、へったら生成り)
- 魔物を UI に出すときは **いつも3D の描画**(forge)。手描きの絵・別の画風の絵は使わない

## 4. 禁止事項

### 4-1. 既存IPに似る形(具体例。似たら作り直し)

| IP | 避ける形 | この作品で気をつける種 |
|---|---|---|
| ポケモン | 黒い猫 + 赤・橙の差し色の炎の猫(ニャビー) | ヒバチネコ |
| ポケモン | 紫の体 + 黄色の帯・しっぽのへび(アーボ) | ヌイヘビ |
| ポケモン | 茶〜肌色の節の芋虫 + 頭の上の1本の角(ビードル) | マッチボウ |
| ポケモン | 灰色の岩の玉が連なった大へび + 頭のとさか(イワーク) | ジャリヘビ |
| ポケモン | 白いロウソク + 炎の頭 + 顔(ヒトモシ) | ロウソクン |
| ポケモン | 綿の雲のつばさの鳥(チルット)、帽子のカラス(ヤミカラス)、剣そのものの魔物(ヒトツキ) | ワタボウシ・オリガラス・ブリキシ |
| ポケモン | 紅白の球、黄色い電気ねずみの形、ほお の赤い丸 | 全種 |
| ドラクエ | **青〜水色のしずく形 + 先のとがった頭 + 笑った口**(スライム)。しずくに王冠 | インキー・しずくの型全体 |
| ドラクエ | 青いまるいコウモリ、レンガ・ブロックを積んだ大男 | ツミキング |
| FF | とんがり帽子 + 真っ暗な顔 + 光る目(黒魔道士) | カゲボウシ |
| デジモン | 機械と生物の半々の体、黄色〜橙の小さな恐竜 | ゼンマイヌ・トケイモリ |
| そのほか | ピンクの球(カービィ)、段ボール箱のロボット(ダンボー)、お腹に画面のある人形(テレタビーズ)、灰色の大きな獣(トトロ) | ツミキング・カミシバイ |

判定のしかた: 1体ずつ、**形・地の色・差し色・属性の組み合わせ**で見る。1つだけ同じなのは問題ない(黒い猫はいてよい)。**2つ以上**が同じになったら直す(黒い猫 + 火の属性 + 橙の差し色 = 不可)。

### 4-2. 画風を崩すもの

- 生成AIの画像、写真のテクスチャ、別の画風のイラスト(UI も同じ)
- 魔物の輪郭線(トゥーン・セルの黒ふち)、トゥーンの段階の陰影、光の当たらない平たい色
- 目にまぶた・まつげ・眉・瞳の星。笑った口・歯・舌
- リアルな毛・うろこ・皮膚。ソフビで型抜きできない細さ(厚み 0.02 未満)
- ブルーム・光のにじみ・色つきの霧。UI の影・グラデーション
- ジオラマにつやを出すこと(水の樹脂と、机の上の道具だけ例外)
- 種ごとに別のマテリアル・別のシェーダー(全員で1つのマテリアル。§1-1)
