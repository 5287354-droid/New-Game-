## 0. テーマ: 箱庭を組み立てなおす

模型師が消えて、ジオラマの「つなぎ目」がほどけた。主人公は、ほどけた箱庭を **一つずつ組み立てなおす**。
プラモデル・模型づくりの「動詞」を、エリアごとに1つずつ覚えていく作りにする。

| 順 | 場所 | 動詞 | 新しいルール(1エリア1つ) | 手に入る力 |
|---|---|---|---|---|
| 1 | ネジマキ村 | **めくる** | 建物の屋根と壁がめくれて、中に入れる。屋根裏・床下にも物がある | — |
| 2 | つみき野 | **まわす** | 回転台を90°ずつ回して、道をつなぐ | — |
| 3 | ランプの森 | **てらす** | ランプの向きで影が動き、影の上だけ歩ける | ピンセット(ぬしの後) |
| 4 | ゼンマイ時計塔 | **つなぐ** | 歯車でつないだものは、いっしょに回る(連動・回る量の比・外すと切れる) | — |
| 能力 | ピンセット | **はめる** | タグのついた部品をつまんで、くぼみにはめる | |
| 予告 | ノリ | **くっつける** | ちぎれた物をくっつける(体験版では見せるだけ) | |

**古いルールの再登場は、新しい力と組み合わせたときだけ**(方針どおり):

- 時計塔の「回る床」は、つみき野の「まわす」の再登場。ただし **ピンセットで歯車をはめて、別の階とつなぐ(連動)** のが新しい。まわす + はめる = つなぐ
- ピンセットを手に入れたあと、つみき野(はしご・橋板・台の上の積み木)、ランプの森(切り絵の木を立てて新しい影を作る)、村(時計塔の入口の歯車)に新しい道がひらく

### 0-1. 難しさの段取り(どのエリアも3段)

どのエリアも **習う → 試す → 組む** の3段で奥へ進む。

| 段 | 意味 | 作り方 |
|---|---|---|
| 習う | ルールを1つだけ、失敗しても損のない場所で見せる | 操作1〜2回。答えが画面に見えている |
| 試す | ルールを「順番」で使う | 操作2〜4回。1回目の操作で自分の側が閉じる、などの小さなひっかけ |
| 組む | ルールを2つの物で同時に使う / 前のルールや力と組み合わせる | 操作4回以上。遠くのハンドル・行ったり来たり・ひとつの物を2つの役に使う |

体験版全体でも、村(やさしい)→ つみき野(1つの台)→ 森(全体の状態)→ 塔(階をまたいだ連動)と、**「動かした物が影響する範囲」がだんだん広がる**ように並べる。

## 3. 魔物の能力と成長

### 3-1. 能力値

能力は HP・MP・こうげき(atk)・まもり(def)・すばやさ(spd)・かしこさ(int)の6つ。`data/monsters.json` の `base` は **Lv1 の値**。

```
能力(L) = floor( base × (1 + 0.1 × (L − 1)) × (1 + 伸びボーナス b) × (1 + パーツの%の合計) )
          ぬし・ボスの HP だけ、さらに × hpMul(カゲボウシ 3.5 / トケイモリ 5)
```

- Lv10 で base の1.9倍、Lv20 で2.9倍、Lv30(体験版の上限)で3.9倍
- 伸びボーナス b は配合で決まる(§5-4)。スカウトした魔物は b = 0
- パーツの% は、生まれつきのパーツ3か所 + おさがり の効果を足したもの(§5-3)
- 種族の強さ(base の合計)の目安: 序盤 96〜104 / 森 104〜108 / 塔 110〜121 / 配合のみ 131〜142 / ぬし 151(+HP倍率)

### 3-2. 経験値とレベル

```
Lv L に上がるのに必要な経験値の合計 T(L) = floor( 2.5 × (L − 1)^2.2 )
   T(2)=2  T(5)=52  T(10)=314  T(15)=830  T(20)=1626  T(30)=4123
1戦闘で1体がもらう経験値 = Σ(敵の xp × 敵のLv ÷ 3)
   戦闘の最後に台の上にいて、たおれていない仲間: 全部 / 控え(手持ちの4〜6体目): 半分 / たおれた仲間: 0
   生まれたての子(配合で生まれて Lv10 になるまで): × 1.5(「組みたて」ボーナス)
```

目安: つみき野の終わりで Lv8〜10、森のぬしで Lv13〜15、塔のボスで Lv18〜21。

お金 = Σ(敵の gold × 敵のLv ÷ 5)。負けると所持金が半分になり、最後に休んだ宿屋で目覚める。

### 3-3. わざ

- わざは1体に4つまで + **パーツわざ** 1つ(おさがりパーツについてくるわざ。5つ目の枠。§5-3)
- レベルで覚えるわざは種族ごとに4〜6個(`learn`)。4つを超えたら、どれを忘れるか選ぶ
- わざ表は `data/skills.json`(40種: 無属性2・水4・火4・紙4・石4・ブリキ6・布4・補助ほか12)

## 4. 戦闘の式

### 4-1. ならび方

- 3対3。**前列2・後列1**。手持ちは6体まで、台に出るのは手持ちの先頭3体
- **後列は、受けるダメージ ×0.7**、敵の近接わざ(`range: melee`)が届かない。前列が2体ともたおれたら、後列が自動で前に出る
- **後列からは近接わざを出せない**(遠くまで届くわざ・補助・回復だけ)
- 「いれかえ」: 前列と後列を入れかえる / 控えと入れかえる。どちらも、そのターンの行動になる(入れかえた魔物は、そのターン動かない)

### 4-2. 行動の順番

```
順番の値 = すばやさ(状態・ばふ込み) × 乱数(0.95〜1.05)
prio: 1 のわざ(かばう)は先に動く。同じ prio の中では、順番の値が大きい方から
```

### 4-3. 命中

```
物理わざ: 命中率 = acc/100 × (0.9 + 0.1 × 使う側のすばやさ ÷ 受ける側のすばやさ)   … 0.5〜1.0 に収める
          × しみ 0.75 × かげのマント 0.5 × 影のターン(カゲボウシ戦)0.25 × shadowfit 0.8
魔法わざ・回復・補助: 必ず当たる(acc を書いたわざだけ、acc/100)
状態異常: 当たったあと、eff.chance(ブリキへの さび は ×2、上限 0.9)
```

### 4-4. ダメージ

```
物理: A = 使う側のこうげき、 D = 受ける側のまもり
魔法: A = 使う側のかしこさ、 D = (受ける側のまもり + 受ける側のかしこさ) ÷ 2

基本 = pow ÷ 16 × A × A ÷ (A + D)
ダメージ = floor( 基本 × 属性 × 素材ぞろい × 後列 × 全体 × 急所 × 特性 × 乱数(0.9〜1.1) )、最低 1

属性      : わざの素材が、相手の素材に強い 1.5 / 弱い 0.67 / ほか 1(無属性は 1)
素材ぞろい: わざの素材 = 使う魔物の素材 なら 1.2
後列      : 受ける側が後列なら 0.7
全体      : target が all なら 0.75
急所      : 物理だけ、1/16 の確率で 1.5(まもりの ばふ を無視)。nocrit の特性なら起きない
特性      : inkpot・burnproof(+10%)など
```

**属性の輪**(矢印の先に強い): 水 → 火 → 紙 → 石 → ブリキ → 布 → 水

計算の例(`base` と上の式から。balancer が調整する前の値):

| 攻撃 | 受ける側 | ダメージ / 相手の最大HP |
|---|---|---|
| ネジコ Lv5 たいあたり | コロイシ Lv4 | 18 / 52(3発) |
| コロイシ Lv4 たいあたり | ネジコ Lv5 | 18 / 47(3発) |
| マッチボウ Lv7 ひのこ(弱点) | ペラリ Lv6 | 41 / 45 |
| ヒバチネコ Lv14 かえんぐるま | カゲボウシ Lv14(ぬし) | 128 / 418 |
| カゲボウシ Lv14 かげふみ | ネジコ Lv14 | 60 / 78 |
| ブリキシ Lv20 きしのとつげき | トケイモリ Lv20(ボス) | 247 / 928 |
| トケイモリ Lv20 じこくのかね(全体) | ブリキシ Lv20 | 79 / 139 |

### 4-5. 回復・ばふ・状態異常

```
回復量 = floor( pow × (1 + 使う側のかしこさ ÷ 40) )      すいとり: 与えたダメージ × drain
ばふ / でばふ: 能力 × mul。5ターン続く。同じ能力に重ねると掛け算、合計 0.5〜2.0 に収める
おりがみのたて: 次に受けるダメージ1回だけ × 0.5
かばう: そのターン、選んだなかまへの単体わざを代わりに受ける(まもり × 1.2 で計算)
```

| 状態 | ターン | 効果 | ならない魔物 |
|---|---|---|---|
| ねむり | 2〜4 | 動けない。ダメージを受けると50%で起きる。スカウト ×1.3 | wakeful |

### 4-6. スカウト

```
成功率 = clamp( scout × (1.5 − 残りHP ÷ 最大HP) × (1 + 0.15 × 同じ素材のなかまの数)
                × レベル差 × 道具 × 状態 × 特性 × ねばり , 0.02, 0.95 )

scout     : 種族ごとの値(monsters.json。0.25〜0.55)
同じ素材  : 台の上(前列+後列)のなかまのうち、相手と同じ素材の数(0〜3)
レベル差  : clamp( 1 + (なかまの平均Lv − 相手のLv) × 0.05 , 0.6 , 1.3 )
道具      : つやだしニス 1.6
状態      : ねむり 1.3
特性      : storyteller(カミシバイのまき物)1.15
ねばり    : 同じ戦闘で失敗するたびに +0.1(最大 +0.3)
ぬし・ボス: 0(カゲボウシは倒したあと配合で、トケイモリは体験版では手に入らない)
```

- スカウトは1ターンの行動。成功すると、そのターンで戦闘が終わる(ほかの敵は逃げる)。演出: 人形がくるっと回って箱に収まる
- 手持ちが6体なら工房の預かり棚へ送る(預かりは60体まで)

### 4-7. にげる・先制

```
にげる成功率 = clamp( 0.5 + (なかまの平均すばやさ − 敵の平均すばやさ) ÷ (2 × 敵の平均すばやさ) , 0.2, 0.95 )
               失敗するたびに +0.15。escape の特性・けむり玉 なら必ず成功。ぬし・ボスからは にげられない
シンボルに後ろから触れる → こちらの先制(1ターン目は敵が動かない)
シンボルに後ろから触れられる → 敵の先制
```

### 4-8. ぬし・ボスの戦い方

**カゲボウシ(ランプの森のぬし)Lv14、HP ×3.5、手下にオリガラス Lv11 ×2**
- 戦場のランプが **2ターンごとに 光 → 影 → 光 …** と切り替わる。次のターンの光/影は、台のはしのランプの絵で前もって見える
- 影のターン: カゲボウシへの **物理わざの命中 ×0.25**、カゲボウシのこうげき ×1.2
- 「ひかりのつぶ」を当てると、次のターンを強制的に光にできる(ホタルビン・ロウソクンが活躍する)
- clearsight(ホタルビンのガラスの羽)を持つ魔物は、影でも命中が下がらない → おさがりパーツの価値を見せる

**トケイモリ(時計塔のボス)Lv20、HP ×5、手下にゼンマイヌ Lv16 ×2(倒すと次のターン補充、最大2回)**
- 戦場は回転台。**針が1ターンに1つ進み、12時(4ターンごと)に「じこくのかね」(全体)**。針は台のはしに見える
- **3時・9時のターンの終わりに台が回り、両方の陣の 前列と後列が入れかわる**(後列 → 前列1、前列1 → 前列2、前列2 → 後列)。後列に置いた回復役が前に出てしまうので、並びを読む
- clockwork(背中の文字盤): 3ターンごとに先に動く

### 5-2. 配合の手順と条件

- 工房の配合台。`breedUnlocked` のあと。**親は2体とも Lv10 以上**。親2体はいなくなる
- 手順(組立説明書の見開き):
  1. 部品A(左の台)・部品B(右の台)に親を置く → 子の種族がシルエットで出る
  2. **おさがりパーツを選ぶ**(§5-3)
  3. **わざを2つまで選ぶ**(§5-5)
  4. 道具を使うか選ぶ(つなぎネジ・金のつなぎネジ・きらりニス)
  5. ①ランナーから部品を切りはなす ②組み合わせる ③パチッとはまる → 台の上でくるりと回る → 名前をつける(そのままでもよい)

### 5-3. おさがりパーツ(この作品のいちばんの売り)

**パーツの場所は 頭・背中・しっぽ の3か所**。胴(型)は受けつがない。

1. 子は、親のどちらかから **1か所** を受けつぐ(どちらの親の、どの場所かを選ぶ)。子のその場所の生まれつきのパーツと入れかわる
2. 受けついだパーツは、子の素材の色と質感で塗り直される(画風を保つ)。ただし「きらり」の親のパーツは、きらり色のまま(コレクションの楽しみ)
3. 受けつげるのは、親が **今つけているパーツ**。親のそのパーツがおさがりなら、おさがりのまま(歴史ごと)受けつぐ → **代々重ねられる**
4. **つなぎネジ**を使うと2か所、**金のつなぎネジ**なら3か所すべて受けつげる(宝箱・ごほうびだけで手に入る)

**パーツの効果**

- どのパーツにも、能力の% がつく(例: ネジコの「ねじ巻き」すばやさ +5%)。生まれつきのパーツの効果も効いている → おさがりは「何かを捨てて何かをもらう」選択
- 1種族につき1か所は **特性**(`traits`)か **パーツわざ**(`skill`)つき。全57パーツ(トケイモリをのぞく19種×3)
  - 特性の例: 綿のつばさ(必ずにげる)、こけ石(毎ターン回復)、ガラスの羽(影でも命中が下がらない)、つぎはぎ(1度だけHP1で耐える)、かぶと(急所なし)
  - パーツわざの例: しおり(おりがみのたて)、ぬい針(ぬいつけ)、けん(きしのとつげき)。**パーツわざは5つ目のわざ枠**として使える(4つの枠を圧迫しない)

**なじみ(代々重ねるしくみ)**

```
おさがりには「なじみ ★」がつく
  親の生まれつきのパーツを受けついだ        → ★1(効果 ×1.0)
  親のおさがり(★n)をそのまま受けついだ      → ★n+1(最大 ★3)
  ★2: 効果 ×1.5、パーツのふちに銀の線
  ★3: 効果 ×2.0、**金つぎ**(金のつぎ目が光る見た目)。特性も強くなる(下の表)
```

| 特性 | ★3(金つぎ)のとき |
|---|---|
| windupStart(ねじ巻き) | 1ターン目 ×1.5 → 2ターン目まで |
| regen(こけ石) | 1/16 → 1/10 |
| endure(つぎはぎ) | 1戦闘1回 → 2回 |
| clearsight(ガラスの羽) | 影・しみ無効 + 命中 +5% |
| storyteller / goldfind | ×1.15/×1.2 → ×1.3/×1.4 |
| ほかの特性 | 能力の% が ×2.0 になるだけ |

→ 同じパーツを3代受けつぐには、配合を3回(Lv10 を3世代)。「この子のねじ巻きは、ひいおばあちゃんから」というのが、見た目でもわかる。

### 5-4. 能力の受けつぎ(伸びボーナス)

```
子は Lv1 から。
伸びボーナス b = min( 0.5 , (親1のLv + 親2のLv) ÷ 200 + 0.5 × max(親1の b, 親2の b) )
代 = max(親1の代, 親2の代) + 1      (スカウトした魔物は 0代)
```

- 例: Lv10 + Lv10 → b = 0.10。その子たち(b=0.10)を Lv20 まで育てて配合 → 0.20 + 0.05 = 0.25
- 代を重ねるほど強くなる(上限 +50%)。図鑑に「◯代目」と出す

### 5-5. わざの受けつぎ

- 親2体の **わざ(4つの枠)** から、2つまで選ぶ。子は Lv1 で覚えるわざ + 受けついだわざ を持って生まれる(4つを超えたら選ぶ)
- パーツわざは、パーツといっしょに受けつぐ(わざの2つには数えない)

### 5-6. おさがりを集めたくなる仕掛け(まとめ)

| 仕掛け | 中身 | ねらい |
|---|---|---|
| **部品表** | おさがりとして **受けついだ** パーツを部品表に登録(57マス)。★3 で受けついだら金のマスに(もう57マス) | 「まだ使っていないパーツ」を埋めたくなる |
| **部品表のごほうび** | 親方から: 5個 つなぎネジ / 10個 きらりニス / 20個 金のピン×3 / 30個 金のつなぎネジ / 45個 親方の称号「部品の目利き」+ 工房の棚に飾り | 配合の回数を増やす |
| **なじみ★と金つぎ** | 同じパーツを3代受けつぐと、効果2倍+金つぎ | 1体の「家系」を育てる |
| **パーツ指定の配合** | 「つみきの冠」をかぶったブリキ → ブリキシ | パーツがレシピの鍵になる |
| **パーツわざ** | 5つ目のわざ枠 | 強い組み合わせを探す |
| **きらりのパーツ** | きらりの親のパーツは、きらり色のまま | めずらしい見た目 |

部品表は図鑑の隣のページ。パーツを指で回して見られる。1か所ずつ「だれから、何代目」の履歴が見られる。

### 8-2. つみき野 — まわす(回転台)

| 段 | 台 | 中身 | 最少の操作 |
|---|---|---|---|
| 習う | A(入口) | 中心のハンドルで、乗ったまま回す。どの方向にも出られる | 1 |
| 試す | B(西)・C(東) | 台の外のハンドル。「回すと自分の側の道が閉じる」ので、ぐるっと回りこむ | 1〜2 |
| 組む | C・D・E | ゴールまで: Cを2つの場所から2回(2つの役に使う)、遠くの陸からEを回し、最後にDを回すと来た道が閉じて北の道がひらく | **4(必須)** |
| 力のあと | B・D・池 | はしご・橋板・**回転台の上にのった積み木**(回る台から部品を取る) | +3か所 |

回転台のパズルは「回すだけ」なので、ハンドルの陸から必ず元の向きに戻せる(4回回すと元どおり)→ 詰まない。ソルバーでも確かめる。

### 8-3. ランプの森 — てらす(光と影)

ランプの向きは森全体で1つ(全体の状態)。つみき野は「1枚の台」だったのが、ここでは **1つの操作でエリア中の道が変わる**。

| 段 | 谷 | 中身 | 最少の操作(ランプ) |
|---|---|---|---|
| 習う | 入口の西の谷 | はじめから影の橋が見えている(操作0で渡れる)。次に、ランプ台で1回変えると、別の橋が出る | 0 → 1 |
| 試す | 東西の谷・谷2 | 「東で半分渡り、島のランプ台で西に変えて残りを渡る」。真上の光で大枝のアーチの影 | 2〜4 |
| 組む | 谷3 | 島でランプを変えると来た橋が消え、行き止まりの橋が出る(順番を読む)。ランプは 東→真上→西 の順にしか回らない | 8(ぬしまで) |
| 力のあと | 谷3の北 | 切り絵の木を運んで台座に立てると、新しい影の橋 | +1か所 |

**影の規則の直し(重要)**: たたき台では、影を落とす木の幹が影の橋の入口をふさいでいて、ランプの森のぬしに届かなかった(§11-2)。**影は幹のマスではなく、幹の1つ南(手前)の列から落ちる** ことにする。影の橋でしか出入りできない陸には、必ずランプ台を置く(詰まないため)。

### 8-4. ゼンマイ時計塔 — つなぐ(連動)

| 段 | 階 | 中身 |
|---|---|---|
| 復習 | 1階 | 文字盤で外周の床を回す(つみき野の「まわす」の再登場)。宝の部屋で ピンセットの積み木 |
| 習う | 2階 → 3階 | 小さい歯車を軸にはめると、2階を回すと3階もいっしょに回る(1:1)。3階には文字盤がない → 2階の回す回数で3階をそろえる(はめる前に回した分も数に入る) |
| 試す | 4階 | 大きい歯車は半分だけ回す(4階を2回で5階が1回)。振り子の通路(BGM の拍) |
| 組む | 4階 → 5階 | **付けかえ**: 5階には文字盤がない。4階で回して5階をそろえ、**歯車を外して** 4階だけ回し戻して出口をひらく |
| ボス | 6階 | 回転台の上で トケイモリ |

1〜5階の各階に、ピンセットでしか開かない宝の部屋が1つずつ(仕様「6階のうち5階は…」を「5つの階に1部屋ずつ」と読んだ)。
